MyDrugs │ Netflix How To Sell Drugs Online (Fast)

This project is a front-end recreation of the fictional MyDrugs website from How to Sell Drugs Online (Fast). I chose it because I liked the show’s bold website design and wanted to see how closely I could recreate it with the skills I had. Building it gave me a chance to practise HTML and CSS as well as JavaScript while learning more about interactive features and the different ways that you can present objects on a webpage.

Features for this project would include:

  • Interactive logo - sends user back to homepage
  • Interactive slides - allows users to scroll and browse different products
  • Animations - moving between slides shows a fade transition
  • Circle bar at the bottom updates to show which slide you are viewing
